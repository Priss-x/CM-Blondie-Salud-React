# Centro Médico Blondie-Salud React

Sistema web para la gestión de un centro médico desarrollado con React y Vite.

## Funcionalidades

- Página principal del centro médico.
- Componentes reutilizables.
- Navbar.
- Hero.
- Footer.
- Registro de pacientes.
- Agendamiento de horas médicas.

## Tecnologías

- React
- JavaScript
- HTML
- CSS
- Vite
